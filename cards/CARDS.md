# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

## c24 事前准入（3 件）— 证据：day-trader-skill 一周 1789 星的核心直觉：止损/目标必须进场前定好，否则不许进场

- **L88 退出判据先行**：L0 出发的车必须先说好在哪停：没有"怎样算失败"的任务不许开跑。L1 任务启动前校验含（成功判据+失败判据+时限）三元组，缺失败判据 → 拒绝开始。L2 断言=①缺失败判据拒启、②三元组齐放行。
- **L89 重放预演**：L0 大动作之前，先拿历史数据"彩排"几遍可能的结局，看最坏的那种能不能接受。L1 用历史轨迹重放 N 个变体，输出结局分布与最坏情况，最坏超承受线 → 建议不做或改方案。L2 断言=①最坏超线建议不做、②分布可接受放行。
- **L90 廉价试错阶梯**：L0 试错要从最便宜的试起：先查文档（免费），再跑小样（几毛钱），最后才上全量（真金白银）。顺序反了要拦。L1 校验试错序列的成本单调性，发现"先贵后便宜" → 拦截并建议重排。L2 断言=①全量先行拦截、②阶梯正确放行。
